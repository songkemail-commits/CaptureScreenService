### 2. 修改Inno Setup脚本

**文件**：`CaptureScreenService/setup.iss`

**修改内容**：

1. **更新软件信息**：
   ```ini
   #define MyAppName "电脑使用监控工具"
   #define MyAppVersion "0.3"
   #define MyAppPublisher "songkemail-commits"
   #define MyAppURL "https://github.com/songkemail-commits/CaptureScreenService"
   ```

2. **设置许可证文件**：
   ```ini
   [Setup]
   LicenseFile=EULA.txt
   ```

3. **添加EULA文件到安装包**：
   ```ini
   [Files]
   Source: "EULA.txt"; DestDir: "{app}"; Flags: ignoreversion
   ```

4. **更新卸载信息**：
   ```ini
   [UninstallDelete]
   Type: files; Name: "{app}\EULA.txt"
   ```
